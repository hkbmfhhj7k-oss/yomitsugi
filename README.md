# Yomitsugi v0.5 — Reader UI

「管理画面」ではなく「自分専用の作品ページ」として読むためのUIへ再構成。

## 変更
- ホーム一覧をコンパクト化
- 一覧から直接「読む」または「概要」
- 作品詳細を入力フォームから独立
- 詳細は作品ヘッダー＋前回まで＋人物＋関係＋イベント＋気になること＋履歴
- シリーズ名をタップすると、そのシリーズだけの一覧ページへ
- 編集は必要なときだけ開く
- 作品ごとの自由セクションを追加可能
- 既存 v0.1〜v0.4 の localStorage (`yomitsugi.v1`) を継続利用

ZIPを展開し、3ファイルをGitHubリポジトリのルートへ上書きしてください。
