# 📚 Yomitsugi — よみつぎ

**「どこまで読んだっけ？」を、できるだけ頑張らずに思い出すためのWeb小説リーディングトラッカー。**

pixiv小説などの連載作品を読んでいると、

- 更新が久しぶりで前の話を忘れた
- どこまで読んだか分からなくなった
- 好きだった一文は覚えているけど、どの作品だったか分からない
- 読んでいる作品が増えすぎて管理できない

ということがよくあります。

Yomitsugiは、作品を「きっちり管理する」のではなく、
**普段どおり読んでいる後ろから、読書の痕跡をそっと拾っていく**
ことを目指した個人用Webアプリです。

---

## ✨ 主な機能

### 📖 作品ライブラリ

読んだ作品を登録して、自分専用の作品ライブラリを作成します。

作者・シリーズ・タグ・URLなどの情報を作品ごとに管理できます。

作品一覧から検索・絞り込みを行い、
シリーズやタグを辿って過去の作品を探すこともできます。

### 📱 iPhoneショートカット連携

共有メニューから作品をYomitsugiへ送信できます。

同じ作品がすでに登録されている場合は重複登録せず、
既存作品の読書記録として扱います。

本文中で選択した文章を共有すると、
直近で読んでいた作品へ引用として保存できます。

「あとでアプリを開いて手入力する」ことをできるだけ減らす設計です。

### ✂️ 読書中の引用

気になった文章や覚えておきたい箇所を保存できます。

引用には取得日時が残り、
作品・キャラクター・関係性などの情報へ後から整理することもできます。

最初から整理する必要はありません。

**とりあえず拾う → 必要になったら整理する**

という使い方を想定しています。

### 🗂️ シリーズ・タグ

作品をシリーズやタグから辿れます。

タグは紙の荷札をイメージしたデザインで、
作品カードからそのままタグ検索できます。

### 📅 読書記録

読書した日時を自動的に記録し、
月ごとの読書履歴として振り返ることができます。

手書きの日記ではなく、
普段の読書から自動的に作られていく読書記録を目指しています。

### 📚 育つ本棚

その月に読んだ作品が、本棚として少しずつ増えていきます。

作品数が増えると本が圧縮され、

- 通常本：1作品
- 装飾本：10作品
- 特装本：50作品
- 豪華本：100作品

のように、本棚そのものが成長していきます。

背表紙はアンティーク洋書をモチーフにしたCSS装丁で、
無料SVGによる植物・花・月・王冠などの箔押し風装飾も使用しています。

「管理画面」ではなく、
**読んだ分だけ自分の小さな書庫が育っていく**
感覚を大切にしています。

---

## ☁️ データ保存

Cloudflare Workers + D1 を使用しています。

ブラウザのローカルデータを表示したあと、
D1に接続できる場合は最新データを読み込む構成です。

作品・タグ・引用・読書履歴などを保存します。

---

## 🌱 Yomitsugiが目指していること

Yomitsugiでは、

**高機能でも、高機能な使い方を要求しない**

ことを重視しています。

毎日きちんと記録したり、
すべての作品に感想を書いたり、
細かく分類し続けなくても使えること。

しばらく使わなくなっても、
また読み始めたときに自然に戻ってこられること。

そして久しぶりに更新された作品を開いたとき、

> 「これ、どんな話だったっけ？」

に答えられる場所になること。

作品情報・読書履歴・引用など、
読んでいる間に残った小さな痕跡から、
過去の読書を思い出せるアプリを目指しています。

前提として開発します。
