# Yomitsugi v0.6 — Inline Edit

作品概要ページを離れず、その場で情報を育てられる版です。

## 変更
- 既存作品の「編集」モーダル導線を撤去
- タイトル・作者・原作・シリーズ・タグ・読書位置を作品ページから直接編集
- 前回まで / 今回起きたこと / メモも各セクション内で編集
- 登場人物 / 関係 / 重要イベント / 気になることは「＋」で個別追加
- 各項目は個別に編集・空欄保存で削除可能
- 自由セクションを作品ページから追加
- 自由セクション名の変更、項目追加・個別編集もその場で可能
- 手動の新規登録だけ従来の入力モーダルを使用
- v0.1〜v0.5の保存データを引き継ぎ

既存の3ファイルをGitHubリポジトリのルートへ上書きしてください。
