# Yomitsugi prototype

Web小説の読書位置・参考文章・シリーズを軽く残す、スマホ向けの初期試作です。

## 現時点でできること
- URL登録（pixiv / 小説家になろう等）
- 作者 / シリーズ / タイトル / URL / 原作の保存
- 読書位置、状態、参考文章、一言メモ
- 「ここまで読んだ」で最終読書日を更新
- URLから続きを読む
- JSONバックアップ / 復元
- ローカル保存（localStorage）

## 意図的にまだ入れていないこと
- pixiv等の本文の自動取得
- 外部AIへの本文・画像送信
- サイトのスクレイピング
- 更新監視
- AI要約 / 人物相関抽出

作者・サービスへの配慮を確認してから実装方式を決めるためです。

## 次の実装候補
1. iPhone共有シートから URL / 選択テキスト / ページタイトルを受け取る
2. 共有情報から作者・シリーズ・タイトル・原作の候補を自動補完
3. シリーズ親子構造と各話の読了位置
4. 「久しぶり」復帰画面
5. 明示的に渡した文章だけを使う要約・人物候補（学習利用されないAPI経路）
