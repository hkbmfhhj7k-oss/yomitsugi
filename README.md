# Yomitsugi v0.3.2 TEST

pixiv小説の公開メタデータを、GitHub Pages上のYomitsugiから直接取得できるか確認する診断版です。

## テスト方法
1. ZIPの3ファイルをリポジトリのルートへ上書き
2. GitHub Pagesの反映後にYomitsugiを開く
3. 上の入力欄へpixiv小説URLを貼る
4. 「pixiv情報取得テスト」を押す
5. 表示された結果をスクリーンショットで共有

通常の保存機能はv0.3.1を引き継いでいます。
このテストはpixiv内部Webエンドポイントへのブラウザ直接アクセス可否を調べるためのもので、恒久実装を確定するものではありません。
