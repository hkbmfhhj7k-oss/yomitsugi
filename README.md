# Yomitsugi v0.2

Web小説を大量に読む人向けの「後ろから痕跡を拾う」読書ログ。

## v0.2
- × / キャンセル時の必須入力バグ修正
- タイトル未取得でも URL だけで「未整理」保存可能
- 単話ごとに取得時タグを保存
- シリーズ名で単話をグルーピング
- タイトル / 作者 / シリーズ / 原作 / タグ / メモ / クリップ / 読書位置を横断検索
- 読書中 / 未整理 / 読了フィルタ
- 同一 URL を再投入した場合は既存記録を開く
- `?url=...&title=...&author=...&series=...&fandom=...&tags=...&text=...` の共有受付パラメータに対応
- v0.1 の localStorage データをそのまま移行
- JSON バックアップ / 復元

## 共有受付
iOSショートカット等から GitHub Pages のURLへクエリを付けて開けば、登録画面へ直接渡せます。

例:
`https://hkbmfhhj7k-oss.github.io/yomitsugi/?url=<共有URL>&title=<タイトル>`

※ pixivアプリから実際に渡せる情報の種類に合わせたショートカットは次段階で調整します。

## 方針
本文を勝手に取得・クロールしたり、外部AIへ送信したりしません。
作者・シリーズ・タイトル・原作・タグ等の自動取得は、各サービスの許容される取得方法を確認したうえで追加します。
